Demo flow

  1. sh demo-panel.sh: a fresh panel on the Pi.
  2. sh ide.sh, open the workspace from the tray icon.
  3. sh viewer.sh: work the panel, capture images in the IDE.
  4. Record and run the test in the IDE. Save it into ~/ide-tests/.
  5. Quit the IDE, then sh run-test.sh: replay without the IDE.

Rules

  • One OculiX at a time. A test run beside the open IDE crashes both, and unsaved tests are lost.
  • Keep your hands off the viewer while a test runs: your mouse moves the Pi's pointer.
  • The viewer always has control; never view-only.
  • In a test, start the panel itself: demo_panel("start") (helper in host/ide-tests/README.md).

Setup (once per tester)

  • Settings: ~/.config/opticnerve/env, mode 600, values in single quotes: ON_HOST, ON_VNC_PASSWORD, ON_LOGIN_PASSWORD; ports and more on page 2.
  • Shortcuts: sh install-shortcuts.sh (-remove deletes them). If one shows as untrusted: right-click, Allow Launching.
  • After a Pi reboot: sh sut.sh start.
Full details: host/poc/README.md in the OpticNerve repository. No passwords on this sheet.

Settings: Addresses, Ports, Passwords

One file for every script: ~/.config/opticnerve/env (mode 600)

Each value comes from the first of: the command line → the environment → the settings file → the default. A - in place of a host or password parameter means "from the settings". Lines are NAME='VALUE'; template host/tools/opticnerve.env.example.
