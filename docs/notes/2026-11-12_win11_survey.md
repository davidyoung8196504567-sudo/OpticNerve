# QNX SDP 8.0 survey: Windows 11 host (2026-11-12)

This is a read-only survey of a fresh QNX SDP 8.0 install on a Windows 11 x86_64 host, made before the first build.
The target is a Raspberry Pi 5 (16 GB) in a Freenove FNK0100K case (4.3in DSI screen, CSI camera, NVMe, speakers).
Nothing was installed, updated, activated or extracted for this survey.

Sources: the SDP's qconfig and `.packages/metadata`, the Software Center's install profile, the Software Center's
cached server package list (fetched 2026-11-11), and a search of file names under the SDP. The Software Center GUI
was not opened, so "update offered" below means "a newer version is in the server list".

`%USERPROFILE%` below is the Windows user's home folder.

## Headline

- **Installed: the Pi 5 *quickstart image*, not the Pi 5 BSP.** The BSP package and the Screen board packages are
  not installed.
- **There is no patchset on the SDP.** The base is 8.0.0. Patchsets 8.0.2 to 8.0.5 are on the server, and nothing
  newer is listed.

## 5. QEMU and mkqnximage

- `com.qnx.qnx800.host.mkqnximage` 0.5.0.00132 is installed (`<SDP>\host\common\bin\mkqnximage` + `.bat`). It
  supports the types qemu, qvm, vbox and vmware.
- **QEMU itself is not installed** on the host. mkqnximage's qemu type needs a separately installed QEMU.
- There is no prebuilt QEMU or x86_64 target image. `images/` holds only `rpi5`.

## 6. Licence

A free non-commercial (QNX Everywhere) licence is in use. Its type and seat count were not read for this survey;
they are shown in the Software Center. The working compile suggests the licence is active.
